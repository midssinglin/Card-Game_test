# 上架檢查清單

這份清單整理把「牌桌學堂」放上應用程式商店前要確認的事。商店規定會變動，送審前請再到官方頁面確認最新版本。

## 1. 定位：模擬博弈、沒有真錢

- [x] 籌碼免費取得、每場重置，沒有現金價值（遊戲內「隱私與聲明」已說明）
- [x] 沒有內購籌碼、沒有兌換或提領、沒有實體獎品
- [ ] 若未來加入內購（例如外觀主題），**不可**販售籌碼或任何能影響輸贏的東西

## 2. 年齡分級

- **Google Play**：填 IARC 分級問卷時，「模擬賭博」要回答「是」。結果通常是 PEGI 12／ESRB Teen 以上，各地區不同。
- **App Store**：年齡分級問卷的「模擬賭博（Simulated Gambling）」選「頻繁／強烈」，分級通常是 17+。
- 遊戲內已建議 18 歲以上使用。

## 3. 隱私

- [x] 設定與紀錄只存在裝置上
- [x] 線上對戰只傳暱稱、匿名編號、牌局內容到 Firebase
- [ ] 送審需要一個公開的隱私權政策網址：可以把遊戲內「隱私與聲明」的文字放到 GitHub Pages（例如 `privacy.html`）
- [ ] App Store 的「App 隱私」問卷：勾選「使用者 ID（匿名）」「遊戲內容」，用途為「App 功能」，不用於追蹤

## 4. 打包

網站版已是可安裝的網頁應用（PWA）：手機瀏覽器打開網址後選「加入主畫面」即可。

要做成商店 App：

```bash
python3 build.py            # 先在專案根目錄產生 docs/
cd mobile
npm install
npx cap add android         # 第一次才需要
npm run android             # 複製網站、同步並打開 Android Studio
# iOS 需要 macOS 與 Xcode：npx cap add ios && npm run ios
```

- Android：在 Android Studio 產生簽署過的 AAB，上傳到 Google Play Console（開發者帳號一次性費用 25 美元）。
- iOS：需要 Apple Developer Program（每年 99 美元），用 Xcode 上傳。

## 5. 素材

- [x] 圖示：`docs/icons/`（512×512、可遮罩版本）
- [ ] 商店截圖：手機直式至少 2 張，可用首頁、牌桌、教學畫面
- [ ] 短描述（80 字內）與完整描述
- [ ] 分類：遊戲 › 紙牌或棋盤；教育
